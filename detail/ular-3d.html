Ular 3D Sensor

Ular klasik dalam arena 3D — kendalikan dengan arah jarimu.

MAIN SEKARANG

Tentang game

Game ular klasik dalam 3D. Kendalikan dengan arah jari telunjuk di depan kamera, geser layar, atau keyboard. Ada apel emas, mode tembus dinding, dan mode 2 Player.

Cara bermain

  1. Arahkan telunjuk ke atas, bawah, kiri, atau kanan.
  2. Makan apel 🍎 supaya ular makin panjang.
  3. Jangan tabrak dinding atau badan sendiri.
  4. Sambar apel emas ⭐ sebelum hilang untuk nilai besar.

Kontrol

📷Kamera

  • Telunjuk menunjuk arah
  • 2 Player: tangan kiri = P1, kanan = P2

👆Sentuhan

  • Geser jari ke arah tujuan
  • P1 sisi kiri, P2 sisi kanan

⌨️Keyboard

  • P1: W A S D
  • P2: tombol panah
  • Spasi: jeda

Mode permainan

👤 1 Player👥 2 Player satu arena (3 ❤ masing-masing)🧱 Opsi tembus dinding

Fitur unggulan

  • ⭐ Apel emas bernilai besar
  • 🐍 Rebutan makanan dengan ular lawan
  • 🛡️ Kebal 2,5 detik setelah muncul lagi

  • Ruangan cukup terang, latar tidak terlalu ramai
