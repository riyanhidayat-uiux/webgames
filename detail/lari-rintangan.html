Lari Rintangan Sensor

Berlari di jalan kota 3D dan gerakkan seluruh badanmu — gaya Kinect.

MAIN SEKARANG

Tentang game

Game ala Kinect: berlari di jalur 3D dan gerakkan seluruh badanmu di depan kamera. Geser badan untuk pindah jalur, lompat melewati pagar, merunduk di bawah palang, dan kumpulkan koin.

Cara bermain

  1. Berdiri ±2 meter dari kamera, kepala sampai pinggang terlihat.
  2. Geser badan ke kiri/kanan untuk pindah jalur.
  3. Lompat melewati pagar dan merunduk di bawah palang.
  4. Kumpulkan koin untuk skor tertinggi.

Kontrol

📷Kamera (tubuh)

  • Geser badan = pindah jalur
  • Lompat = lompati pagar
  • Merunduk = lewati palang

⌨️Keyboard

  • ← / → pindah jalur
  • ↑ atau Spasi: lompat
  • ↓: merunduk

👆Sentuhan

  • Geser ke arah yang diinginkan

Mode permainan

👤 1 Player

Fitur unggulan

  • 🏙️ Gedung dan pohon realistis
  • 🪙 Koin dan rintangan bervariasi
  • ⚙️ Kepekaan sensor bisa diatur

Sebelum mulai

Berdiri ±2 m, ruangan cukup terang. Alternatif keyboard/sentuhan tersedia.

  • Izinkan akses kamera saat diminta (jika memakai kamera)
  • Panduan kamera otomatis memeriksa posisi, jarak, dan cahayamu sebelum game dimulai
  • Ruangan cukup terang, latar tidak terlalu ramai
  • Nyalakan suara untuk pengalaman terbaik
  • Butuh internet untuk memuat Three.js & pendeteksi tubuh
